# Seed Templates Script

## Overview

The `seed_templates.js` script reads `seed_templates.json` and inserts insight templates into the Supabase database.

## Prerequisites

1. **Run migrations first:**
   ```bash
   supabase db push
   ```

2. **Run seed.sql to create domains:**
   ```bash
   # In Supabase dashboard SQL editor, or via CLI:
   psql -h your-db-host -U postgres -d postgres -f supabase/seed.sql
   ```

3. **Set environment variable:**
   ```bash
   export SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
   ```

## Usage

```bash
node scripts/seed_templates.js
```

## What It Does

1. ✅ Checks that all domains exist
2. ✅ Creates 36 categories (subdomains) under core domains
3. ✅ Creates Romance & Love context module
4. ✅ Creates 8 romance subdomains
5. ✅ Inserts templates from JSON
6. ✅ Creates template_contexts associations for romance-tagged templates

## JSON Format

Your `seed_templates.json` should have:

```json
{
  "metadata": {
    "version": "2.0",
    "total_templates": 75,
    "domains": [...]
  },
  "templates": [
    {
      "slug": "template_slug",
      "insight_text": "Template text",
      "domain": "relational_strategies",
      "category": "Conflict Navigation",
      "subcategory": "Smoothing",
      "subtype": "pattern",
      "search_variants": [...],
      "search_keywords": [...],
      "prevalence": "very_common",
      "context_tags": {
        "romantic_context": true,
        "romance_subdomain": "conflict_repair_romance",
        "is_romance_exclusive": false
      }
    }
  ]
}
```

## Notes

- Script skips templates that already exist (by slug)
- Embeddings are NOT generated - run separately
- Search vectors are auto-generated by database trigger
